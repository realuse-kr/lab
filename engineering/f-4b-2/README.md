# engineering/f-4b-2 — 이산화 규칙마다 응답이 달라지는 샘플링 비율은 얼마일까

시간 상수 0.1초인 1차 플랜트(ZOH 모델)와 Kp 2, Ki 40인 PI 제어기를 Forward Euler, Backward Euler, Tustin 세 규칙으로 이산화하고, 샘플링 비율(샘플링 주파수 ÷ 연속 시간 폐루프 −3 dB 대역폭)을 바꿔 가며 세 규칙의 응답이 서로 얼마나 다른지(규칙 간 최대 차이)와 폐루프가 안정한지(극점 크기)를 계산한다. 가상 파라미터 계산이며 실제 기기의 값이 아니다.

## 파일
- `rule_gap.py`: 본문 코드와 같다. 대역폭을 구하고 비율 3, 5, 10, 20, 40, 80, 160의 규칙 간 최대 차이와 극점 최대 크기를 출력한다. NumPy와 SciPy가 필요하다.
- `save_results.py`: 비율 4~160의 17개 값, 규칙 간 최대 차이가 목표값의 5%, 2%, 1%가 되는 비율, 규칙별 불안정 한계, 연습문제 답을 `results_f4b2.json`으로 저장한다. `rule_gap.py`와 같은 폴더에서 실행한다.
- `results_f4b2.json`: 본문 표와 그림의 숫자가 나온 결과 파일이다.

## 실행
```
python -I rule_gap.py
python save_results.py
```
Python 3.13, NumPy 2.5.3, SciPy 1.18.1에서 실행했다. `save_results.py`는 같은 폴더의 `rule_gap.py`를 import하므로 `-I` 없이 실행한다. MATLAB 명령은 본문에만 있고 실행하지 않았다.

## 연습문제
상수를 바꾸려면 `rule_gap.py` 3번째 줄의 `KP, KI, TAU, TEND`만 고치면 된다. 폐루프 전달함수 `NUM`, `DEN`은 같은 줄의 상수에서 만들어지고, 대역폭과 샘플링 주기의 환산은 함수가 다시 계산한다. 파일을 바꾼 직후 다시 실행할 때 이전 실행의 캐시가 남아 있으면 `__pycache__` 폴더를 지운다.

1. 샘플링 주기 20 ms는 샘플링 비율로 얼마이고, 그 주기에서 규칙 간 최대 차이는 얼마인가? (`max_gap(0.02)`를 호출한다.)
2. Ki를 20으로 바꾸면 대역폭은 어떻게 달라지고, 비율 20에서 규칙 간 최대 차이는 얼마인가?
3. 규칙 간 최대 차이는 비율을 80에서 40으로 줄일 때 몇 배가 되는가?

## 풀이
1. 비율은 10.6이고 규칙 간 최대 차이는 0.145다.
2. 대역폭은 4.73 Hz에서 3.18 Hz로 줄고, 비율 20에서 규칙 간 최대 차이는 0.056이다.
3. 2.09배다.
