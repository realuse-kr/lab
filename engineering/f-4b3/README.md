# F-4B3 제어기를 처음부터 이산시간으로 설계하면 무엇이 달라질까

플랜트 P(s) = 1/(0.1s + 1), 연속 시간 PI 제어기 Kp = 2, Ki = 40, 샘플링 주기 T = 20 ms에서 에뮬레이션 여섯 규칙과 직접 이산 설계를 비교한다.

## 파일
- `direct_design.py`: 목표 극점, 직접 이산 설계 계수, 에뮬레이션 여섯 규칙, 폐루프 극점, 폐루프 편차를 계산하고 출력한다.
- `save_results.py`: 결과를 `results_f4b3.json`으로 저장하고 계수, 극점, 분모를 다른 방법으로 다시 구해 대조한다.
- `results_f4b3.json`: 본문 표의 원본 값.

## 실행
```
python3 direct_design.py
python3 save_results.py
```
Python 3.13, NumPy 2.5.3, SciPy 1.18.1에서 실행했다. 다른 버전은 실행하지 않았다.

## 연습문제
1. `direct_design.py`의 `T_DEFAULT`를 0.04로 바꿔 실행한다. 직접 이산 설계의 폐루프 극점이 목표와 같은지, 에뮬레이션 여섯 규칙의 거리가 어떻게 달라지는지 확인한다.
2. `KP`를 4로 바꾸고 `T_DEFAULT`를 0.02로 둔다. 목표 극점이 실수 두 개가 될 때 `direct_design`이 만드는 계수와 폐루프 편차를 확인한다.
3. 직접 이산 설계의 (c0 + c1)/T가 Ki와 같아지려면 어떤 조건이 더 필요한지 식으로 적어 본다.

## 풀이 요약
1. T = 0.04에서 직접 이산 설계는 극점 거리 0, 폐루프 편차 9.2%였다. 에뮬레이션은 거리 0.132~0.528, 폐루프 편차 29.2~55.6%였다. 이 값은 같은 코드를 `T_DEFAULT = 0.04`로 실행한 결과다.
2. Kp = 4이면 연속 시간 폐루프의 극점이 s = −40, −10으로 실수 두 개가 된다. 직접 이산 설계는 c0 = 3.038, c1 = −2.487이고 폐루프 편차는 0.0%였다. 코드의 `pole_distance`가 극점 두 개를 거리가 짧게 짝지어 재므로 거리도 0이 된다.
3. 직접 이산 설계에 적분 이득 조건 (c0 + c1)/T = Ki를 하나 더 두면 식이 세 개가 되어 계수 두 개로는 맞출 수 없다. 제어기에 계수를 하나 더 두는 방법을 생각해 볼 수 있고 이번에는 계산하지 않았다.
