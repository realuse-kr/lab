# 시뮬레이션 간격과 제어기 주기는 같은 걸까

가상 2차 시스템(고유각주파수 10 rad/s, 감쇠비 0.3)에 비례 제어기(KP=3)를 붙이고,
제어기 주기(TS)와 시뮬레이션 간격(dt)을 따로 정했을 때 읽히는 오버슈트가 어떻게 달라지는지 본다.
제어기는 TS마다 출력을 한 번 정하고 다음 주기까지 그대로 유지한다. 적분은 Forward Euler다.

## 실행

Python 3와 NumPy가 필요하다. MATLAB은 쓰지 않는다.

```
python overshoot_ts_vs_dt.py   # 주기별로 dt=TS와 dt=TS/100의 오버슈트를 출력한다
python save_results.py         # 같은 계산에 dt=TS/1000을 더해 results_f3b2.json으로 저장한다
```

## 파일

- `overshoot_ts_vs_dt.py`: 계산 본체(함수 없는 짧은 스크립트).
- `save_results.py`: 결과 표(차이는 소수 둘째 자리 값끼리 뺀다), 주기 효과, 추가 계산 오차, 간격 100분의 1과 1000분의 1의 차이를 json으로 저장한다.
- `results_f3b2.json`: 위 스크립트를 실행한 결과 파일.

## 연습문제

`overshoot_ts_vs_dt.py`의 주기 목록을 `[0.02]`(20ms)로 바꿔 실행하면 `dt=TS/100`의 오버슈트는 얼마인가.

정답: 79.20%. 같은 줄의 `dt=TS`는 556.00%로 나온다. 계산이 흔들리는 값이라 제어기 성능으로 읽지 않는다.
