# F-4B3.2 샘플링 주기를 늘리면 에뮬레이션과 직접 이산 설계 중 어느 쪽이 먼저 벗어날까

플랜트 P(s) = 1/(0.1s + 1), 연속 시간 PI 제어기 Kp = 2, Ki = 40에서 샘플링 주기 T를 1 ms부터 120 ms까지 바꿔 가며 에뮬레이션 여섯 규칙과 직접 이산 설계의 폐루프 편차를 비교한다.

## 파일
- `sampling_sweep.py`: 목표 극점, 직접 이산 설계 계수, 에뮬레이션 여섯 규칙, 폐루프 극점, 폐루프 편차를 계산하고, 폐루프 편차가 처음 한도를 넘기 직전의 샘플링 주기와 폐루프가 처음 불안정해지는 샘플링 주기를 출력한다.
- `save_results.py`: 결과를 `results_f4b3_2.json`으로 저장하고 계수, 극점, 분모를 다른 방법으로 다시 구해 대조한다.
- `results_f4b3_2.json`: 본문 표의 원본 값. `grid`에 1 ms 단위 전체 결과가 있다.

## 실행
```
python3 sampling_sweep.py
python3 save_results.py
```
두 파일은 같은 폴더에서 실행한다. Python 3.13, NumPy 2.5.3, SciPy 1.18.1에서 실행했다. 다른 버전은 실행하지 않았다.

## 연습문제
1. `sampling_sweep.py`의 `TAU`를 0.2로 바꿔 실행한다. 폐루프 편차 10% 한도의 샘플링 주기가 규칙마다 어떻게 달라지는지 확인한다. `W0_PREWARP`는 TAU = 0.1에서 정한 값이므로 24 그대로 두고, 프리워핑 Tustin의 값은 참고로만 본다.
2. `KP`를 4로 바꾸고 `TAU`는 0.1로 둔다. 목표 극점이 실수 두 개일 때 직접 이산 설계의 폐루프 편차가 샘플링 주기 5, 20, 40, 80 ms에서 얼마인지 확인한다.
3. 직접 이산 설계의 폐루프 편차를 0으로 만들려면 폐루프 분자와 분모에서 맞춰야 하는 식이 몇 개인지 세어 본다.

## 풀이 요약
1. TAU = 0.2에서 폐루프 편차 10% 한도의 샘플링 주기는 Forward Euler 17 ms, Backward Euler 16 ms, Tustin 21 ms, 스텝 불변 17 ms, 극·영점 매칭 21 ms, 프리워핑 Tustin 19 ms, 직접 이산 설계 34 ms였다. 같은 코드를 `TAU = 0.2`로 실행한 결과다.
2. Kp = 4이면 연속 시간 폐루프 극점이 s = −10, −40으로 실수 두 개가 된다. 직접 이산 설계의 폐루프 편차는 5, 20, 40, 80 ms에서 모두 0.0%였다. 에뮬레이션 여섯 규칙 중 가장 작은 편차는 3.15%, 17.4%, 52.1%, 124.3%였다. T = 5 ms에서 직접 이산 설계의 영점 −c1/c0는 0.9512이고 exp(−10T)도 0.9512다. 제어기의 영점이 폐루프 극점 하나와 맞아 폐루프가 1차 시스템으로 줄어든 경우다. 다른 T에서 영점이 같은지는 확인하지 않았다.
3. 폐루프 분모는 z의 계수와 상수항에서 식 2개, 분자도 z의 계수와 상수항에서 식 2개로 모두 4개다. 계수는 c0, c1 두 개뿐이라 일반적으로 모두 맞출 수 없다. 연습문제 2는 영점이 극점과 맞는 특별한 경우다.
