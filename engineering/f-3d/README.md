# F-3D 고정 스텝 시뮬레이션, RK4면 충분한 때는 언제일까

시간상수 10ms인 감쇠 방정식 A와 시간상수가 더 짧은 방정식 B를 같은 간격으로 0~60ms 푼다. A의 60ms 값을 상대 오차 1% 이하로 맞추고 B의 계산값이 줄어드는 가장 작은 스텝 수를, Forward Euler와 RK4(4차 룽게-쿠타법)로 구해 함수 호출 수를 비교한다.

## 파일
- `euler_vs_rk4.py` — 글에 실린 30줄 코드. Python 3 표준 라이브러리만 쓴다. 실행하면 호출 수 네 줄을 출력한다.
- `save_results.py` — 같은 폴더에서 실행하면 `results_f3d.json`을 만든다(RK4 안정 상한, 증폭인자 식 확인, 오차 목표별 뒤바뀌는 지점).
- `results_f3d.json` — 위 스크립트의 실행 결과.

## 실행
```
python3 euler_vs_rk4.py
python3 save_results.py
```
실행 환경: Python 3.13. 출력은 표와 같다(Forward Euler 3590/3590/3590/30002회, RK4 88/864/8624/86168회).

## 연습문제
연습 2와 3처럼 `TAU_A`나 `T`를 바꿀 때는 `A_60 = e^(−T/TAU_A)`도 같이 바꾼다. `A_60`을 그대로 두면 정확한 해가 달라 `min_steps`가 끝나지 않는다.

1. 오차 목표를 5%로 바꾸면 방정식 B의 시간상수 2ms에서 두 방법의 호출 수는 각각 몇 번인가.
2. 방정식 A의 시간상수를 20ms로 바꾸면 뒤바뀌는 지점은 어느 쪽으로 움직이는가. 이유를 안정 상한으로 설명하라.
3. 계산 구간 T를 120ms로 늘리면 RK4의 안정 상한으로 정해지는 호출 수는 어떻게 변하는가.

## 해답
1. Forward Euler 710회, RK4 88회다. `0.01`을 `0.05`로 바꿔 실행한 값이다.
2. 20ms로 바꾸면 Forward Euler는 900회(B 2ms 기준)로 줄고 RK4의 안정 한정 호출 수(약 172 ÷ τ)는 그대로라, 뒤바뀌는 지점이 B의 시간상수 약 0.19ms 쪽으로 옮겨 간다. B 0.2ms에서 RK4 864회 대 Forward Euler 900회, 0.1ms에서 1,728회 대 900회였다.
3. 구간 120ms로 늘리면(오차 1% 유지) B 0.2ms에서 RK4가 864회에서 1,728회로 2배가 되고, Forward Euler는 14,344회다.

## 범위
서로 독립인 감쇠 방정식 두 개, 고정 간격, 두 방법만 확인했다. 스텝 크기를 바꾸는 방법, 연립 모델, 비선형 모델은 확인하지 않았다.
