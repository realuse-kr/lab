# F-4B4.2: ZOH가 만드는 T/2 지연과 위상 여유

PI 제어 루프에서 ZOH(영차 유지)의 위상 감소와 위상 여유를 계산하는 코드와 결과 파일이다.
블로그 글은 realuse.kr의 「ZOH로 출력을 유지하면 지연이 얼마나 생기는지 계산하기」다.

## 파일
- `phase_margin_zoh.py`: ZOH 응답, 세 루프(ZOH 루프, T/2 지연 루프, 이산 루프)의 교차 각주파수와 위상 여유를 계산하고 표를 출력한다.
- `save_results.py`: T = 1~40 ms를 1 ms 단위로 계산해 `results_f4b4_2.json`에 저장하고 점검 항목(check_*) 여덟 개를 출력한다.
- `results_f4b4_2.json`: 저장된 결과.
- `run_output.txt`: `python3 phase_margin_zoh.py`의 출력.

## 실행 환경
Python 3.13.18, NumPy 2.5.3, SciPy 1.18.1에서 `python3 phase_margin_zoh.py`와 `python3 save_results.py`를 실행했다. 두 파일은 이 폴더에서 실행한다.
MATLAB 예제(글의 접이식 상자)는 실행하지 않았다.

## 계산 조건
플랜트 P(s) = 1/(TAU·s + 1), PI 제어기 C(s) = KP + KI/s, KP = 2, KI = 40, TAU = 0.1.
ZOH 응답은 (1 − exp(−jωT))/(jωT)다. 이산 루프는 ZOH로 이산화한 플랜트와 Tustin으로 이산화한 제어기를 쓰고 지연은 넣지 않았다.

## 함께 바꿔야 하는 값
KP, KI, TAU를 바꾸면 개루프 크기가 1이 되는 각주파수가 `W_LO = 1.0`과 `W_HI = 200.0` 사이에 있어야 한다. 교차 각주파수가 이 구간 밖이면 `crossover_and_margin` 함수의 assert가 실패한다. 이때 `W_LO`나 `W_HI`를 함께 바꾼다.
이산 루프는 구간 끝을 0.999·π/T로 잡으므로 T를 바꾸면 자동으로 따라간다.

## 연습문제
아래 풀이값은 같은 코드를 직접 실행한 값이다.

1. TAU를 0.2로 바꾸고 T = 20 ms에서 ZOH 루프의 위상 여유를 구하라. ZOH가 없는 개루프의 위상 여유와 비교하라.
   - 풀이: ZOH가 없는 개루프는 교차 각주파수 15.52 rad/s, 위상 여유 55.7도다. ZOH 루프는 교차 각주파수 15.48 rad/s, 위상 여유 46.8도이고 이산 루프는 46.9도다. 줄어든 각도는 약 8.9도이며 ωc·T/2 = 15.52 × 0.010 rad ≈ 8.9도와 같다.
2. KP를 4로 바꾸고 T = 20 ms에서 ZOH 루프와 T/2 지연 루프의 위상 여유를 구하라. 두 값은 같은가?
   - 풀이: ZOH 루프는 67.7도, T/2 지연 루프는 67.1도, 이산 루프는 66.5도다. ZOH가 없는 개루프는 교차 각주파수 40.00 rad/s, 위상 여유 90.0도이고 ZOH 루프의 교차 각주파수는 38.99 rad/s다. 교차 각주파수가 더 많이 내려가서 두 값의 차이가 0.6도로 늘었다.
3. `margin_zoh`를 이용해 T를 1 ms씩 늘리며 ZOH 루프의 위상 여유가 처음 60도 미만이 되는 T를 찾아라(KP = 2, KI = 40, TAU = 0.1).
   - 풀이: 18 ms에서 60.46도, 19 ms에서 59.78도이므로 19 ms다.

## 확인한 것과 확인하지 않은 것

- 미확인: MATLAB, 다른 플랜트·제어기, 다른 이산화 규칙, 실제 기기.
