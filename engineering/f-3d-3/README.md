# f-3d-3: RK45의 출력 간격과 시간 스텝 크기

시간상수 10ms인 감쇠 방정식 dx/dt = −x/τ, x(0) = 1을 0ms부터 60ms까지 SciPy `solve_ivp(method="RK45")`로 풀면서, 결과를 읽는 시각 사이의 간격(출력 간격)을 10ms에서 0.1ms까지 바꿀 때 함수 평가 횟수와 60ms 값의 상대 오차가 어떻게 달라지는지 비교한다. 허용 상대 오차(rtol)는 1e-6, 허용 절대 오차(atol)는 1e-12로 고정했다. 해석해는 x(t) = e^(−t/τ)이고 60ms 값은 e^(−6) = 0.002479이다. 방정식은 하나이고 다른 방정식과 결합하지 않는다.

출력 간격을 지정하는 방법 세 가지를 비교한다.

- `t_eval`: 출력 시각 목록만 넘긴다. 시간 스텝 크기는 RK45가 정한다.
- `max_step`: 출력 간격을 시간 스텝 크기의 상한으로 넘긴다.
- 고정 시간 스텝(계산 중 시간 간격을 바꾸지 않음) RK4: 시간 스텝 크기 h가 곧 출력 간격이다.

## MATLAB

MATLAB 명령은 제시만 하며 실행하지 않았다. 이 저장소의 숫자는 모두 Python 실행값이다. `ode45`는 `tspan`에 원소를 세 개 이상 주면 그 시각의 해를 돌려주며, 시간 스텝 경계가 그 시각에 맞춰지는 것은 아니다. 시간 스텝 크기의 상한은 `odeset`의 `MaxStep`이다. MATLAB과 SciPy는 오차 판정식이 달라서 같은 숫자를 넣어도 함수 평가 횟수가 같다고 가정하지 않는다.

```
opts = odeset(RelTol=1e-6, AbsTol=1e-12);
[t, x] = ode45(@(t, x) -x/0.010, 0:0.001:0.060, 1, opts);
opts2 = odeset(opts, MaxStep=0.001);
```

## 연습문제

1. `KW`의 `rtol`을 1e-3으로 바꾸고 `atol`은 1e-12로 둔다. 출력 간격 0.1ms에서 `t_eval`로 지정한 함수 평가 횟수와 60ms 상대 오차, `max_step`으로 지정한 함수 평가 횟수는 얼마인가.
2. `max_step`에 `np.inf`, 2.4ms, 2.3ms, 2.0ms를 넣고 함수 평가 횟수, 수용된 시간 스텝 수, 시도한 시간 스텝 수를 비교하라. 수용된 시간 스텝은 RK45가 오차 판정을 통과시킨 시간 스텝이고, 시도한 시간 스텝 수는 거부된 것까지 센 값이며 (함수 평가 횟수 − 2) ÷ 6이다.
3. `rk4(0.00025)`의 함수 평가 횟수와 60ms 상대 오차를 구하라.

## 연습문제 정답 (같은 환경에서 실행한 값)

1. `t_eval`은 함수 평가 50회, 60ms 상대 오차 3.0e-3이다. `max_step`은 3602회로 rtol 1e-6일 때와 같다. 시간 스텝 크기가 0.1ms로 제한되어 600개 시간 스텝(3602회)이 된다.
2. 함수 평가 횟수는 `np.inf` 164회(수용 26개, 시도 27번), 2.4ms 158회(수용 26개, 시도 26번), 2.3ms 164회(수용 27개, 시도 27번), 2.0ms 182회(수용 30개, 시도 30번)이다. 2.4ms에서는 시도한 시간 스텝 수가 수용된 시간 스텝 수와 같아서 거부된 시도가 없고, 그만큼 164회보다 적다. 상한이 방법이 고른 시간 스텝 크기(2.3ms 안팎)에 걸리기 시작하면 함수 평가 횟수가 달라지고, 2.3ms 아래에서는 상한이 낮을수록 늘어난다.
3. 함수 평가 960회, 60ms 상대 오차 2.0e-8이다. RK4의 함수 평가 횟수는 4 × 시간 스텝 수다.

## 이 저장소가 다루지 않는 것

- SciPy의 다른 방법(`RK23`, `DOP853`, `Radau`, `BDF`)과 MATLAB의 다른 해법
- 방정식이 둘 이상이거나 서로 결합한 모델, 이벤트 함수를 쓰는 경우
- 실행시간 측정(비교한 것은 함수 평가 횟수다)

`EXACT`는 `TAU`와 `T`에서 계산되므로 두 값을 바꿀 때 따로 고칠 것은 없다.
