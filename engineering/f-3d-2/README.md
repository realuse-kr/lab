# f-3d-2: RK45의 허용 상대 오차(rtol)와 허용 절대 오차(atol)가 시간 스텝 크기를 정하는 방식

시간상수 10ms인 감쇠 방정식 dx/dt = −x/τ, x(0) = 1을 0ms부터 60ms까지 SciPy `solve_ivp(method="RK45")`로 풀면서 rtol과 atol을 바꿔 함수 평가 횟수, 수용된 시간 스텝 크기, 60ms 값의 상대 오차를 비교한다. 해석해는 x(t) = e^(−t/τ)이고 60ms 값은 e^(−6) = 0.002479이다. 방정식은 하나이고 다른 방정식과 결합하지 않는다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `rk45_tolerance.py` | 글 본문의 코드. atol을 바꿔 가며 함수 평가 횟수, 수용된 시간 스텝 수, 60ms 상대 오차를 출력한다. |
| `save_results.py` | `results_f3d2.json`을 만든다. 수용 조건과 시간 스텝 크기 갱신 규칙을 직접 구현해 SciPy 결과와 맞대어 본다. |
| `results_f3d2.json` | 본문 표와 그림의 숫자, 확인 항목의 결과. |

## 실행

같은 폴더에서 실행한다.

```
python3 rk45_tolerance.py
python3 save_results.py
```

실행 환경: Python 3.13, NumPy 2.5.3, SciPy 1.18.1 (`results_f3d2.json`의 `scipy`, `numpy` 항목). `rk45_tolerance.py`의 출력은 아래와 같다.

```
atol=1e-12 함수 평가 164회 시간 스텝 26개 오차 1.6e-06
atol=1e-08 함수 평가 158회 시간 스텝 25개 오차 2.3e-06
atol=1e-06 함수 평가 110회 시간 스텝 17개 오차 7.1e-05
atol=0.0001 함수 평가 56회 시간 스텝 8개 오차 3.1e-03
atol=0.01 함수 평가 26회 시간 스텝 4개 오차 3.4e-01
```

## MATLAB

MATLAB 명령은 제시만 하며 실행하지 않았다. 이 저장소의 숫자는 모두 Python 실행값이다. `ode45`는 `odeset`의 `RelTol`, `AbsTol`로 같은 허용 오차를 받는다. 오차 판정식은 SciPy와 다르다(SciPy는 atol + rtol·|x|, MATLAB은 max(RelTol·|x|, AbsTol)). 따라서 같은 숫자를 넣어도 함수 평가 횟수가 같다고 가정하지 않는다.

```
opts = odeset(RelTol=1e-6, AbsTol=1e-12, Stats="on");
[t, x] = ode45(@(t, x) -x/0.010, [0 0.060], 1, opts);
```

## 연습문제

1. `rk45_tolerance.py`에서 rtol을 1e-6 대신 1e-3으로 바꾸고 atol을 1e-12로 둔다. 함수 평가 횟수와 60ms 상대 오차는 얼마인가.
2. `TAU`를 0.020으로 바꾸고 `T`를 0.120으로 바꾼다. atol 1e-12, 1e-8, 1e-6, 1e-4의 함수 평가 횟수는 본문 표와 어떻게 다른가.
3. `TAU`는 0.010으로 두고 `T`만 0.120으로 늘린다. 같은 네 atol에서 60ms가 아니라 120ms 값의 상대 오차를 비교하라. 어느 atol부터 오차가 rtol(1e-6)보다 100배 넘게 커지는가.

## 연습문제 정답 (같은 환경에서 실행한 값)

1. 함수 평가 50회, 수용된 시간 스텝 7개(거부된 시도 1회), 60ms 상대 오차 3.0e-3. rtol을 1e-6에서 1e-3으로 1000배 키웠을 때 오차는 rtol보다 약 3배 큰 3.0e-3이다. rtol은 시간 스텝 하나의 허용치이고 최종 오차의 상한이 아니다.
2. 함수 평가 횟수가 164, 158, 110, 56회로 본문 표와 같다. 시간상수와 계산 구간을 같은 비율로 바꾸면 해의 모양과 시간 스텝 수가 그대로이기 때문이다(상대 오차도 1.6e-6, 2.3e-6, 7.2e-5, 3.2e-3으로 거의 같다).
3. 함수 평가 횟수는 320, 236, 146, 74회이고 120ms 값의 상대 오차는 3.2e-6, 2.0e-4, 1.7e-2, 0.76이다. 해석해 x(120ms) = e^(−12) = 6.1e-6이 작아져 atol 1e-8부터 오차가 rtol의 100배(1e-4)를 넘는다.

## 이 저장소가 다루지 않는 것

- SciPy의 다른 방법(`RK23`, `DOP853`, `Radau`, `BDF`)과 MATLAB의 다른 해법
- 방정식이 둘 이상이거나 서로 결합한 모델, 오차 노름이 결과를 바꾸는 경우
- 실행시간 측정(비교한 것은 함수 평가 횟수다)

`EXACT`는 `TAU`와 `T`에서 계산되므로 두 값을 바꿀 때 따로 고칠 것은 없다.
