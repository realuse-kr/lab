# F-4B4 제어가 한 샘플 늦으면 위상 여유가 얼마나 줄어드는지 계산하기

플랜트 P(s) = 1/(0.1s + 1), PI 제어기 Kp = 2, Ki = 40인 개루프에 지연을 넣고 위상 여유가 얼마나 줄어드는지 계산한다. 연속 시간 루프에는 지연 T를 e^(−sT)로, 샘플링 주기 T인 이산 루프에는 한 샘플 지연을 z^−1로 곱한다.

## 파일
- `phase_margin_delay.py`: 개루프, 교차 각주파수, 위상 여유, 이산 폐루프 극점 크기를 계산하고 표의 값을 출력한다.
- `save_results.py`: 결과를 `results_f4b4.json`으로 저장하고, 교차 각주파수와 위상 여유를 닫힌 식으로 다시 구해 대조한다.
- `results_f4b4.json`: 본문 표의 원본 값. `continuous.grid`에 지연 1~60 ms, `discrete`에 샘플링 주기 1~40 ms 결과가 있다.

## 실행
```
python3 phase_margin_delay.py
python3 save_results.py
```
두 파일은 같은 폴더에서 실행한다. Python 3.13, NumPy 2.5.3, SciPy 1.18.1에서 실행했다. 다른 버전은 실행하지 않았다. `save_results.py`의 점검 8개는 Kp = 2, Ki = 40, 시간 상수 0.1초에서 모두 True였다. 다른 값에서 점검을 돌려 보지는 않았다.

## 연습문제
1. `phase_margin_delay.py`의 `TAU`를 0.2로 바꿔 실행한다. 교차 각주파수, 지연 없는 위상 여유, 지연 마진이 어떻게 달라지는지 확인한다.
2. `KP`를 4로 바꾸고 `TAU`는 0.1로 둔다. 교차 각주파수와 위상 여유, 지연 마진을 구한다.
3. 샘플링 주기 10 ms인 이산 루프에서 지연 샘플 수를 1에서 2로 늘리면 위상 여유가 얼마나 더 줄어드는지 `margin_disc(0.01, 2)`로 확인한다.

함께 바꿔야 하는 값: `KP`, `KI`, `TAU`를 바꾸면 개루프 크기가 1이 되는 각주파수가 `W_LO = 1`과 `W_HI = 200` rad/s 사이에 있어야 한다. 구간 밖이면 `crossover_and_margin`의 assert가 "교차점이 구간 밖이다"를 내고 멈춘다. 그때는 `W_LO`, `W_HI`를 함께 바꾼다.

## 풀이 요약
1. TAU = 0.2에서 교차 각주파수는 15.52 rad/s, 지연 없는 위상 여유는 55.7도, 지연 마진은 62.6 ms였다. 지연 10 ms를 넣은 위상 여유는 46.8도로 8.9도 줄었고 15.52 × 0.010 rad = 8.9도와 같다. 같은 코드를 `TAU = 0.2`로 실행한 결과다.
2. Kp = 4이면 교차 각주파수가 40.00 rad/s이고 개루프 위상이 −90도라서 위상 여유가 90.0도, 지연 마진은 39.3 ms다. 지연 10 ms를 넣으면 위상 여유는 67.1도로 22.9도 줄었다. 위상 여유가 더 커도 교차 각주파수가 커서 지연 마진은 TAU = 0.1, Kp = 2의 52.9 ms보다 짧다.
3. 샘플링 주기 10 ms에서 지연 없는 위상 여유 66.0도가 한 샘플 지연에서 52.2도(13.8도 감소), 두 샘플 지연에서 38.4도(27.5도 감소)였다. 두 샘플 지연의 감소량이 한 샘플 지연의 두 배다. `save_results.py`가 샘플링 주기 1~40 ms에서 이 관계를 점검한다.
