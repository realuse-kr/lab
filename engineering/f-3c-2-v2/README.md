# f-3c-2-v2: 시간상수가 다른 두 감쇠 방정식과 전진 오일러법의 시간 간격 상한

서로 독립인 감쇠 방정식 dx/dt = −x/τ 두 개(방정식 A: τ = 10ms, 방정식 B: τ = 2ms, 둘 다 x(0) = 1)를 같은 시간 간격 h로 전진 오일러법(Forward Euler)으로 60ms까지 계산한다. h를 바꿔 가며 계산값의 크기가 줄어드는지 커지는지 확인한다.

이 모델은 실제 장치의 측정값이 아니라 설명을 위한 가상의 수학 모델이다.

## 핵심 식

- 전진 오일러법: x(다음) = x(지금) + h × (−x(지금)/τ) = g × x(지금)
- 증폭인자: g = 1 − h/τ. n스텝 뒤 계산값은 x(0) × g^n
- 계산값의 크기가 스텝마다 줄어 0으로 가는 조건(수치적 안정성): |g| < 1, 즉 0 < h < 2τ. |g| = 1은 경계
- 방정식 A의 상한은 20ms, 방정식 B의 상한은 4ms. 두 방정식이 h를 같이 쓰므로 상한은 4ms
- h = 4ms에서는 방정식 B의 g = −1이라 계산값의 크기가 1로 유지되고 부호만 바뀐다(감쇠하지 않는다)

## 파일

- `euler_two_decay.py` : h = 1·3·4·5·10·15ms로 60ms까지 계산해 증폭인자와 계산값 크기 여섯 줄을 출력한다. Python 3 표준 라이브러리만 쓴다.
- `save_results.py` : 같은 계산, 상한 바로 양쪽(3.9·4.0·4.1ms, 15스텝) 비교, 정확한 해를 `results_f3c2v2.json`에 저장한다.
- `results_f3c2v2.json` : 위 계산의 결과 파일.

## 실행

```
python3 euler_two_decay.py
python3 save_results.py
```

## 확인한 범위

- 서로 독립인 감쇠 방정식 두 개와 전진 오일러법만 확인했다.
- 방정식끼리 서로 영향을 주는 모델과 다른 계산 방법은 확인하지 않았다.
- h가 안정성 상한보다 작다는 것은 계산값의 크기가 줄어든다는 뜻이며 정확도를 보장하지 않는다. 예: h = 3ms에서 60ms 뒤 방정식 A의 계산값은 0.0008, 정확한 해는 0.0025.
- MATLAB 코드는 제공하지 않는다.
