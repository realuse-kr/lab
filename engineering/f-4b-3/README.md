# engineering/f-4b-3 — 샘플링 주파수를 대역폭의 몇 배로 잡으라는 규칙은 믿어도 될까

시간 상수 0.1초인 1차 플랜트(ZOH 모델)와 Kp 2, Ki 40인 PI 제어기를 Forward Euler, Backward Euler, Tustin 세 규칙으로 이산화하고, 샘플링 비율(샘플링 주파수 ÷ 연속 시간 폐루프 −3 dB 대역폭)을 바꿔 가며 이산 응답이 연속 시간 폐루프의 스텝 응답과 얼마나 다른지(편차)와 이산 개루프의 위상 여유를 계산한다. 샘플링 주파수를 정하는 경험 규칙이 말하는 비율을 이 조건의 대역폭 기준 비율로 읽은 값도 함께 저장한다. 가상 파라미터 계산이며 실제 기기의 값이 아니다.

## 파일
- `rule_multiple.py`: 본문 코드와 같다. 대역폭을 구하고 비율 6, 8, 10, 20, 25, 30, 40, 100의 편차와 위상 여유를 출력한다. NumPy와 SciPy가 필요하다.
- `save_results.py`: 비율 4~160의 17개 값, 허용 편차 5%, 2%, 1%에 필요한 비율, 위상 손실 15°, 10°, 5° 이내에 필요한 비율, 출처가 말한 비율의 환산값, 연습문제 답을 `results_f4b3.json`으로 저장한다. `rule_multiple.py`와 같은 폴더에서 실행한다.
- `results_f4b3.json`: 본문 표와 그림의 숫자가 나온 결과 파일이다.

## 실행
```
python -I rule_multiple.py
python save_results.py
```
Python 3.13, NumPy 2.5.3, SciPy 1.18.1에서 실행했다. `save_results.py`는 같은 폴더의 `rule_multiple.py`를 import하므로 `-I` 없이 실행하고 약 1분 걸린다. MATLAB 명령은 본문에만 있고 실행하지 않았다.

## 연습문제
상수를 바꾸려면 `rule_multiple.py` 3번째 줄의 `KP, KI, TAU, TEND`만 고치면 된다. 폐루프 전달함수 `NUM`, `DEN`은 4번째 줄에서 같은 상수로 만들어지고, 대역폭과 샘플링 주기의 환산은 함수가 다시 계산한다. 파일을 바꾼 직후 다시 실행할 때 이전 실행의 캐시가 남아 있으면 `__pycache__` 폴더를 지운다.

1. 샘플링 주기 20 ms는 샘플링 비율로 얼마이고, 그 주기에서 세 규칙의 편차와 Tustin의 위상 여유는 얼마인가? (`deviation(0.02)`와 `phase_margin(0.02, "Tustin")`을 호출한다.)
2. Ki를 20으로 바꾸면 대역폭은 어떻게 달라지고, 비율 20에서 세 규칙의 편차는 얼마인가?
3. 세 규칙 중 가장 큰 편차가 목표값의 5% 이하가 되는 가장 작은 비율은 얼마인가? (비율을 바꿔 가며 `deviation`의 최댓값을 확인한다.)

## 풀이
1. 비율은 10.6이다. 편차는 Forward Euler 0.118, Backward Euler 0.180, Tustin 0.124이고 Tustin의 위상 여유는 59.1°다.
2. 대역폭은 4.73 Hz에서 3.18 Hz로 줄고, 비율 20에서 편차는 Forward Euler 0.043, Backward Euler 0.090, Tustin 0.066이다.
3. 32.5다.
