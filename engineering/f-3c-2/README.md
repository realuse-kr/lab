# f-3c-2: 빠른 값이 하나 섞이면 계산 간격의 한계는 어디서 정해질까

시간상수 10ms인 값과 2ms인 값을 한 시뮬레이션에서 Forward Euler로 계산하고, 간격을 바꿔 가며 값의 크기가 줄어드는지 커지는지 확인한다. 시간상수와 시작값은 가상 값이다.

## 파일

- `fast_value_limit.py` : 간격 1·3·4·5·10·15ms로 60ms를 계산해 표의 여섯 줄을 출력한다. Python 3 표준 라이브러리만 쓴다.
- `save_results.py` : 같은 계산과 한계 바로 아래·위(3.9·4.0·4.1ms) 비교를 `results_f3c2.json`에 저장한다.
- `results_f3c2.json` : 위 계산의 결과 파일.

## 실행

```
python fast_value_limit.py
python save_results.py
```

## 확인한 범위

- 서로 영향을 주지 않는 두 값(시간상수 10ms, 2ms)과 Forward Euler만 확인했다.
- 값들이 서로 얽힌 모델, 다른 계산 방법은 확인하지 않았다.
- 간격이 한계보다 작다는 것은 계산값이 커지지 않는 조건이며 정확도를 보장하지 않는다.
