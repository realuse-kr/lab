# F-3 연습문제와 해답

가상 2차계(ζ=0.32, ωn=11 rad/s, 스텝 입력)를 쓴다. 오차는 계산 격자점에서 닫힌식과의 최대 절대차다. 결과는 가상 파라미터 시뮬레이션이며 실제 장치 측정이 아니다. 실행은 Python으로만 했고 MATLAB 코드는 실행하지 않았다.

## 문제 1. 전진 Euler가 터지는 간격
구간을 20 s로 늘리고 h=0.05 s와 h=0.08 s로 전진 Euler를 돌려 최대 |x|를 비교하라. 안정 한계 h < 2σ/ωn²를 먼저 계산해 예측과 맞는지 확인하라.

해답: σ=3.52이므로 한계는 2×3.52/121 = 0.0582 s다. h=0.05는 한계 아래라 최대 |x|=1.90, 마지막 시각 오차 2.34e-05로 수렴한다. h=0.08은 한계 위라 최대 |x|=2.41e10으로 발산한다.

## 문제 2. RK4 목표 오차 예측
마지막 간격(h=0.000625 s)의 RK4 오차로 e = C·h⁴의 C를 구하고, 목표 오차 1e-6에 필요한 단계 수를 예측한 뒤 실제로 돌려 확인하라.

해답: C=146.88, 예측 h=0.009084 s, 단계 수 N=221. 실제 오차는 1.0053e-6으로 목표에 거의 닿는다.

## 문제 3. 개선 Euler(Heun)의 차수
한 단계에 우변을 2번 계산하는 개선 Euler로 같은 간격 표를 만들고 오차 차수를 구하라.

해답: 간격을 절반으로 줄일 때 오차 배율은 약 4.00(4.04에서 4.00으로 접근), 로그-로그 기울기 2.008이다. 즉 2차 방법이다.
