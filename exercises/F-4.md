# F-4 연습문제와 풀이

모든 수치는 가상 파라미터다. 풀이의 숫자는 `python/f2_control/discretization_map.py`와 같은 식으로 계산했다.

## 문제 1. Forward Euler의 한계 주기
연속 제어기의 극점이 s = −5 ± j40 rad/s이다. Forward Euler로 옮길 때 극점이 단위원 안에 남는 샘플링 주기 T의 상한을 구하고, T = 0.006 s와 0.007 s에서 |z|를 확인하라.

**풀이.** 한계는 T < 2σ/(σ²+ω²) = 10/(25+1600) = 0.006154 s이다.
T = 0.006 s에서 |z| = 0.9992로 안, T = 0.007 s에서 |z| = 1.0048로 밖이다.

## 문제 2. Backward Euler가 불안정한 극점을 안정해 보이게 만드는 조건
연속 시간에서 불안정한 극점 s = +50 rad/s를 Backward Euler로 옮긴다. |z| < 1이 되는 T의 범위를 구하라.

**풀이.** z = 1/(1−sT)이므로 |z| < 1은 |1−50T| > 1과 같고, T > 2/50 = 0.04 s이다.
T = 0.03 s에서 |z| = 2.0, T = 0.04 s에서 1.0, T = 0.05 s에서 0.667이다. 0.05 s에서는 불안정한 극점이 단위원 안에 들어온다.

## 문제 3. SciPy의 gbt와 세 규칙
`scipy.signal.cont2discrete`의 `method="gbt"`에서 `alpha`를 0, 0.5, 1로 바꿔 H(s) = 1/((s+4)(s+25))를 T = 0.02 s로 옮기고, 분모의 근을 `method="euler"`, `"bilinear"`, `"backward_diff"` 결과와 비교하라.

**풀이.** alpha = 0은 Forward Euler, 0.5는 Tustin, 1은 Backward Euler와 같은 대응이다. 분모의 근이 같은 값으로 나온다.
alpha = 0은 0.5와 0.92, alpha = 0.5는 0.6과 0.9231, alpha = 1은 0.6667과 0.9259이다. 이 근은 극점 −25와 −4를 각 규칙으로 옮긴 값과 같다.
