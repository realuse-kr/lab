# campfire sounds (옹기종기 모닥불)

옹기종기 모닥불 페이지(realuse.kr)가 재생하는 소리 파일. GitHub Pages로 공개한다.

이 폴더의 소리 파일은 저장소의 MIT 라이선스가 아니라 아래 표의 각 출처 라이선스를 따른다.

| 파일 | 내용 | 출처 | 라이선스 |
|---|---|---|---|
| fire.mp3 | 장작 타는 소리 29초 (112kbps로 다시 압축) | "Fireplace Sound loop" by PagDev, https://opengameart.org/content/fireplace-sound-loop | CC0 |
| chirps.mp3 | 들판귀뚜라미 울음 80개, 0.3초 칸마다 하나 (대역 필터, 잘라 재배치) | "Gryllus campestris 53", © Natural History Museum, London (BioAcoustica), https://commons.wikimedia.org/wiki/File:BioAcoustica_994_2_Gryllus_campestris_53.flac | CC BY 3.0 https://creativecommons.org/licenses/by/3.0/ |
| stream.mp3 | 작은 개울 40초 | "Park ambiences" by Thimras, https://opengameart.org/content/park-ambiences | CC0 |
| rain.mp3 | 빗소리 45초 | "Rain (loopable)" by Ylmir, https://opengameart.org/content/rain-loopable | CC0 |
